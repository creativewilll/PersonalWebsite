# Media Prompt Patterns

Prompt archetypes for generating cover images, video frame references, and
carousel slide visuals for @willspurly Instagram content.

## Brand Visual Constants

- **Primary palette**: Deep purple (#7c3aed) → Golden yellow (#eab308)
- **Secondary**: White, near-black (#1a1a2e), soft lavender (#ede9fe)
- **Style**: Cinematic tech, clean minimalism, subtle neon accents
- **Mood**: Professional but approachable, futuristic but grounded
- **Never**: Clip art, stock photo vibes, cartoonish illustrations, busy backgrounds

## Reel Frame Archetypes

### 1. Talking-Head Start Frame
```
Cinematic portrait of a young professional man in a clean workspace,
natural lighting from left, shallow depth of field, laptop visible but
blurred in background, purple-and-yellow bokeh orbs, shot at eye level,
confident neutral expression, 8k quality, no text overlays.
```

### 2. Screen-Record Canvas Frame
```
Top-down view of a MacBook Pro screen showing [TOOL] interface with
[SPECIFIC NODES/ELEMENTS], dark mode UI, clean workspace around laptop,
ambient purple LED strip lighting visible at edges, shallow depth of
field on screen content, professional product photography style.
```

### 3. Before/After Split Frame
```
Split-screen composition: left side shows chaotic desk with sticky notes
and multiple browser tabs (warm/red tones, slight blur), right side shows
clean minimal setup with single automation dashboard glowing green
(cool/purple tones, sharp focus), dramatic lighting contrast, cinematic.
```

### 4. Result/Receipt Frame
```
Close-up of a dashboard or notification showing [SPECIFIC METRIC],
green success indicators, clean dark UI, subtle purple glow around the
metric number, shallow depth of field, feels like a candid screenshot
but elevated to cinematic quality.
```

### 5. End Frame / CTA Frame
```
Same environment as start frame but with a comment bubble or DM
notification overlay glowing in brand purple, the keyword '[KEYWORD]'
visible in the comment, subtle confetti or success particles,
warm golden lighting shift indicating completion/reward.
```

## Carousel Slide Archetypes

### Cover Slide
```
Bold statement on dark purple gradient background, large white sans-serif
text (3–7 words max), subtle golden accent line or glow behind text,
clean geometric shapes in background at 10% opacity, professional and
magazine-editorial feel, aspect ratio 4:5.
```

### Interior Content Slide
```
Dark background (#1a1a2e) with single concept visualized: [CONCEPT].
Large readable text in white, one accent color highlight on key word
(golden yellow), minimal iconography if needed, generous whitespace,
aspect ratio 4:5.
```

### Diagram/Flow Slide
```
Clean flowchart or node diagram on dark background showing [PROCESS]:
[NODE A] → [NODE B] → [NODE C]. Nodes in purple with golden connection
lines, minimal labels in white sans-serif, no clutter, feels like a
premium software interface, aspect ratio 4:5.
```

### Last Slide (Save CTA)
```
Warm gradient (purple to golden) background, large text "Save this."
or "DM me '[KEYWORD]'" in white bold, @willspurly handle in smaller
text below, subtle animated feel (slight glow), clean and direct,
aspect ratio 4:5.
```

## Video Script Visual Directions

### Screen Recording Overlay Style
- Dark mode everything (n8n dark canvas, Cursor dark theme, terminal dark)
- Zoom into relevant sections (don't show full screen chaos)
- Mouse movements: deliberate, not frantic
- Highlight active node/element with purple outline annotation
- Text overlays: white, bottom-left or top-center, max 5 words

### Talking-Head Style
- Frame: chest-up, slightly off-center (rule of thirds)
- Background: clean, minimal, hint of tech (monitor glow, LED strip)
- Lighting: key light from 45° left, fill from right, purple/warm balance
- Movement: lean in on key points, hand gestures in frame
- Eye line: direct to camera for hooks and CTAs, slight off-camera for teaching

### B-Roll Patterns
- Hands typing on keyboard (close-up, shallow DOF)
- Phone notification sliding down (screen recording)
- Dashboard metrics ticking up (screen recording + zoom)
- Coffee mug next to laptop (establishing "work morning" vibe)
- Terminal commands running (satisfying text scroll)

## Prompt Modifiers (append to any base prompt)

### Quality Modifiers
- "8k resolution, photorealistic, cinematic lighting"
- "Shot on Sony A7IV, 35mm f/1.4, natural bokeh"
- "Professional product photography, studio lighting"

### Mood Modifiers
- "Confident, minimal, tech-forward"
- "Warm but professional, approachable expertise"
- "Dramatic reveal, high contrast, editorial"

### Anti-Patterns (never include in prompts)
- Specific AI tool brand names (e.g., "Midjourney style")
- Text that needs to be legible (AI image gen can't reliably render text)
- Multiple people or complex scenes
- Memes, jokes, or pop culture references in visuals
- Overly futuristic/sci-fi (stay grounded in real workspaces)
